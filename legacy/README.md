# Archived application

[`cuadc_2026/`](cuadc_2026/) is the complete former repository tree. Its
files were moved together, without changing their contents, when the clean V1
framework root was created. It is a reference and source of reusable modules,
not a dependency of the new root.

To run its historical offline tests, enter `legacy/cuadc_2026/` and use the
dependencies and commands documented there. The new root's CI tests only the
new framework.
