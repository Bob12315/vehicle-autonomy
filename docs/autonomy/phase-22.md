# P22：停车后受控重规划

2026-10-19。**PASS：限定本机 Rover 仿真的停车后重规划。**

## 实现与边界

`GoalNavigation` 只将当前有效地图造成的 `navigation_path_blocked:` 归为可恢复原因。先完成旧 Action 的 Stop 退出屏障及 `end_run`，再运行独立 `safe_recovery` Mission 确认停车、Disarm。双 SEND 关闭后，延时获取新输入、后台规划、完整准入，建立新 Run/Lease。旧计划、排队命令和晚到结果不能恢复执行。

默认 `max_replans=0`。显式策略最多 2 次重规划，重试间隔 0.1–5 s，总任务期限 1–600 s；规划至多 20 s，单次跟踪仍至多 70 s，原停车屏障仍为 8 s。可增加 0–0.25 m **规划余量**；没有降低执行校验的最小距离。

地图丢失、时钟或 Frame epoch 改变、定位失效、对齐漂移、计划文件变化、断链、Safety 拒绝与操作者取消不通过重规划绕过。重试次数和总期限不会无限续期。规划仍使用不可变输入和独立原生进程；没有删除 P19 的只读 READY/禁用 SEND 条件。

## 物理场景约束

动态地图验收使用实际 Gazebo 激光、SLAM Toolbox 占据栅格和 Nav2，4096 根真实射线，未知格仍阻挡。显式使用**遥测里程计对齐地图**（`use_scan_matching: false`），避免将物体变化引起的扫描匹配跳变误当作可恢复路径变化。扫描匹配版本出现超过 0.10 m 的对齐变化仍停车，不声称支持任意动态 SLAM 场景或连续动态避障。

默认平滑跟踪保留 P20 行为。停转策略为单独选项，不能因新增策略改变默认车的已验收行为。重规划场景显式选择停转策略，保留原车 SDF 和 SITL 默认标定；试验过的高转向增益未通过，已移除，不列为支持配置。最终采用的标定以场景 manifest 和黑盒 PARM 为准。
