# 首次接入与分阶段现场检查

适用日期：2026-10-21 之后首次现场测试。当前发布版仅提供硬件只读诊断；
`hardware_controlled` 会被拒绝，Web 不会解锁或驱动车辆。软件可部署不等于
车辆已通过安全验收。以下每阶段须有人在场记录结果，上一阶段不通过即停止。

## 1. 不通驱动动力的实物确认

- [ ] 隔离场地、警戒线、观察员和能直接触达物理急停的操作者到位。
- [ ] 确认车型、飞控实际固件/板型、供电、共地、保险、线序和驱动使能。
- [ ] 物理急停直接切断驱动使能/动力；验证它独立于 RK3588、网络、Web、LLM
  与 Python。软件零速度不算该项通过。
- [ ] 驱动动力断开或机械隔离，核对 STM32/双 DAC 的上电、掉电、断线及看门狗
  输出；测量电平及左右方向，不凭接口名称推定。STM32/DAC 生产控制适配尚未实现。
- [ ] 确认左右差速机械结构、轮径、轮距、车体最大包络；当前两种仿真车不是实车标定。
- [ ] 确认无轮速编码器时的实际反馈来源；不能把命令速度当作测量速度。

## 2. 只读接线与诊断

```bash
ssh pi@192.168.50.2
cd /home/pi/vehicle-autonomy/current
export VAF_PYTHON=/home/pi/vehicle-autonomy/venv/bin/python
./scripts/onboard.sh status
ls -l /dev/serial/by-id/
ip -brief address
cat /sys/class/net/eth0/carrier
v4l2-ctl --list-devices
```

- [ ] 保持管理口 `eth1 / 192.168.50.2` 不变；禁止因猜测 LiDAR 网段而重配 SSH 网口。
- [ ] 新飞控连接只读确认设备 by-id、MAVLink 源 system/component、ArduPilot Rover
  类型、固件标识、未武装、模式及遥测频率。当前模板 telemetry=null，需按
  [部署说明](hardware_deployment.md)复制并填写真实设备；不运行旧的 `--allow-send`
  台架脚本，不自动改参数或请求数据流。
- [ ] 开阔场地核对 GPS/EKF/IMU、GPS fix/卫星/HDOP、姿态方向与实际朝向；检查
  EKF 原点、NED/ENU、速度符号、更新年龄、源 boot epoch 和重新连接。
- [ ] 机载墙钟已观察到约一天偏差。先记录偏差，再由操作者安排安全的同步方案；
  当前程序使用单机单调时间，尚无经认证的跨设备采集时钟映射。
- [ ] LiDAR 供电与网线连接到确认的非管理口；核实载波、真实设备/目标 IP 和
  MSOP/DIFOP UDP 端口。仅被动捕获并保存真实 PCAP/rosbag；无数据不能通过。
- [ ] 按真实安装测量 `base_link→lidar`、相机光学 Frame、朝向/高度、车体自遮挡、
  地面与安全保护区；保存来源版本。禁止沿用仿真外参作为实物事实。
- [ ] 相机实际采集到连续视频后检查光照、FPS、延迟、断流和恢复；当前 ISP 节点
  无有效图像，设备节点本身不算已接入。相机投影与识别仍需实测标定/模型验收。

## 3. 静止的传感器、地图和失效验证

- [ ] 确认真实 PointCloud2、LaserScan、capture/receive 时间与 frame 正确；数据
  断流、延迟、重排、错误时间戳和重启均能显示失效且不刷新旧样本年龄。
- [ ] 真实墙体、低矮/高悬/贴近车体障碍均有探测证据，地面过滤未移除危险物体。
- [ ] 地图构建、保存/回读、初始定位、相对位移、转向和重定位用独立测量验收。
  当前 SLAM 候选 `control_eligible=false`，不能切换为活动控制源。
- [ ] GPS 跳变/丢失、地图过期、雷达断流、相机失效、LLM/网络断开、应用崩溃与
  重启的静止测试留证。真实链路失联时停车结果仍是 UNCONFIRMED。
- [ ] 验证重新连接默认只读、新 epoch、旧任务/旧命令不重放；所有新运动仍需新授权。

## 4. 运动前的软件与硬件退出门槛

本轮未完成实车受控运行组合、近场扫描的硬件 writer 装配、实车 Nav2 动态障碍层、
活动 SLAM 定位、模式切换停车/重新准入，以及 STM32/DAC 执行器联调。
**这些软件/标定门槛完成前，不进入运动阶段；不能靠修改 SEND 字段解锁本版本。**

- [ ] 有经评审的唯一 writer、明确 SafetyPolicy、双 SEND、Lease、deadman、TTL、
  速度/转向/围栏限值、来源仲裁、失联策略与旧会话隔离。
- [ ] 独立物理急停/驱动失能验收 PASS；操作者实测停止距离与失联后的真实行为。
- [ ] 两定位模式分别通过现场门槛；切换必须停车并确认、清除旧命令、重新准入
  坐标/定位和授权新任务，不允许在线直接换源或自动恢复旧任务。
- [ ] 所有关键 FAIL 已解决并重新测试；BLOCKED 不得签成 PASS。

## 5. 仅在上述门槛完成后的未来低速阶段

每项都由现场操作者单独授权并确认结果，今晚不执行：驱动隔离台架 → 短直线 →
停止/失能 → 低速转向 → 宽裕空地单目标 → 可控静态障碍 → 传感器失效停车。
首段限速须依据实车测量设定，可从不高于 0.1 m/s 的人工约束开始；该数值是未来
现场试验建议，不是本轮已验证的实车能力。每次测试记录源版本、参数、人员、距离、
速度、制动时间、停止确认来源及急停可用性，失败后不继续下一阶段。
