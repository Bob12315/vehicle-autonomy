# Web UI 中文界面

2026-10-29。保持现有原生 JavaScript、样式、导航及认证和车辆执行边界。

## 页面范围

- 统一登录、错误提示和退出登录。
- 车辆总览、三车型车辆控制、安全反馈与诊断入口。
- 任务库、模板、任务编辑器、节点参数、运行监控、历史、共享变量和执行事件。
- 旧版任务编辑器、动作实验室、独立只读任务控制台。
- 工具管理、工作区、日志、设置，以及 RViz 快捷入口。

控制中心和车辆控制页的左侧导航均可打开“任务编排”（`/studio`）。
模式采用中文说明并保留飞控代码，例如“引导（GUIDED）”。任务节点和动作支持中文搜索。

## 数据与权限

共享展示词表位于现有 `auth.js` 静态资源内，各页面复用，不新增服务器路由。
静态页面直接使用中文；动态组件使用相同词表，展示更新时也会应用中文。
只读证据、原始日志、JSON、程序标识、用户命名和可编辑内容保留原文。
工具与软件名称（Gazebo、RViz2、QGroundControl）、单位和协议缩写保持可辨识。
常见失败提供中文解释，原始失败原因保留在诊断及提示中。

下拉框显示中文，但 `value`、节点类型、动作名、参数键、接口请求及导出定义保持原协议。
未设置显式值的下拉项在替换文字前固定原值。共享变量的数据值不参与界面翻译。
未知状态仍显示“未知”，没有以汉化补齐缺失遥测或放开操作。
登录、会话、控制权、发送开关和车辆安全逻辑沿用原实现。

## 使用

已运行的服务直接读取静态资源，刷新页面即可加载中文，无需因汉化重启飞控。
尚未启动时，在项目目录执行 `./scripts/start_copter_sim.sh`，按终端提示登录，
访问 `http://127.0.0.1:8781/control` 或 `http://127.0.0.1:8781/studio`。
启动仿真不自动解锁、起飞或执行任务。
