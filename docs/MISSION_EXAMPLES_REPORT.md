# Mission 示例与验证（2026-10-31）

新增六份 Studio schema 2 定义，位于 `simulation/missions/examples/`：
只读三次采样、上锁状态三态分支、地面车直线三站巡检、多旋翼悬停降落、
多旋翼双点返航和固定翼跑道任务。参数、适用装配和操作说明见该目录 README。

## 接入方式

例子作为版本化 JSON 资源随源码与 wheel 提供；实现加载器位于 app/mission_designer。
模板只在明确自有仿真上下文安装。控制台启动时通常没有 Driver，因此进入任务库时也会
检查新接入车辆并补齐模板。已有用户模板、草稿和发布版本不会被覆盖。
构造或安装模板不创建 Run、不打开 SEND、不发出运动指令，不要求 studio-demo。
每次创建草稿仍需核对实际 target，发布和运行继续通过原验证器和执行链。

## 验证

- 最终完整单元测试 948 项通过（123.898 秒，无失败或跳过）。新增覆盖真实 Registry
  合同编译、错误车型拒绝、只读循环结果、缺失状态 UNKNOWN、动态接入与模板不覆盖、
  硬件上下文不安装仿真模板。
- 使用控制台相同的 World + 独立签名 Driver 进程装配，通过 HTTP 保存、验证、发布、运行。
  两个只读例子分别在三车型运行；四个运动例子按车型运行，共 10 个 Run 全部 SUCCEEDED。
- 所有只读 Run 的命令证据为空，系统/Action SEND 和 lease 均关闭。工作进程的只读
  源时钟维护与车辆运动命令分开，不把“零运动命令”表述为“链路零字节”。
- 独立 Gazebo truth 校验地面车三个目标、多旋翼两个航点及起飞高度、最终落地位置和速度。
  地面车在第三站结束，最终距部署原点约 2.75 米、速度约 0.002 m/s，已上锁；
  多旋翼两个任务最终距 home 均小于 0.007 米、速度为零，已落地上锁。
- 固定翼起飞、目标配置、盘旋、RTL、AutoLand 全链通过；最终距 home 约 30.98 米、
  速度约 0.0043 m/s，满足受测跑道边界，已落地上锁。模式/目标 ACK 不冒充物理到达。
- 三个测试会话的退出均 release_safe，仿真 Session 清理均 COMPLETE。
- wheel 包含六份 JSON 与使用说明；在仓库外的干净环境安装后，三车型分别读取到
  3、4、3 个适用示例，未依赖源码目录或本机软件索引。

最终证据：`artifacts/mission-examples-20261031/final-simulation-checks.json`；
分别对应 rover-clean、copter-managed、plane-managed 下的 examples-summary.json。

## 失败原件与限制

最初使用进程内旧 MissionFixture 并行运行回归，出现时序/观测新鲜度围栏拒绝。
改用当前控制台的独立工作进程装配，不修改安全阈值。最初地面车折线及有桌面仿真负载时
的停车确认失败原件保留；正式示例采用直线三站。在用户关闭其桌面仿真后，独立地面车
复测通过，未把 UNKNOWN/FAILED 改为成功，也未跳过停车与清理检查。

本次证据限定于当前本机受测场景与负载。没有新增任意折线导航、动态避障、硬件运动或
载荷功能，也未将 Mission 示例通过扩大为 P26 或实机认证。
