# Web 导航与页面整理验收（2026-10-30）

本轮修复各页菜单名称、编号和入口不一致，以及本机部署仍展示未配置的远程工具页面的问题。
所有当前 Mission / Control Center 页面共用一份导航描述和渲染组件。

日常入口统一为车辆总览、仿真中心、车辆控制、任务编排、工具与系统。
本机 Gazebo GUI、RViz2、QGC、日志和系统信息集中到 `/center`。
未配置的远程工具、工作区、日志和设置从菜单隐藏，旧书签转到对应的可用页面；
有远程配置的部署保留高级入口，包括尚未上线和已经离线的主机。
动作实验室移入高级功能，旧任务编辑器只保留兼容地址，不出现在日常菜单。
工具页增加加载提示与按钮就绪状态，并修复长车辆编号、安装路径和进程目录的窄屏溢出。
